# Zuvo audit — 2026-11-20

Three roles: security engineer (OWASP ASVS L2), UAT tester, UI/UX engineer. Production was touched
only by read-only requests (response headers, `/v1/health`, Lighthouse on the public sign-in and
Help pages). Everything else ran locally: code review, the E2E stack with in-memory MongoDB, and
Playwright on Chromium. Screenshots (336) are kept outside the repo, in the owner's
`ZUVO-screenshots\audit\` folder, named `<screen>-<width>-<theme>-<lang>.png`.

Real IPs, hostnames and secrets are masked in this report on purpose (the repository is public).

## Checked and found OK

- **Headers (live):** CSP without `unsafe-eval` and with `frame-ancestors 'none'`, HSTS (2 years,
  subdomains), `nosniff`, Referrer-Policy, Permissions-Policy, COOP/CORP on the app and the API.
- **Sessions:** host-only `__Secure-` cookie, HttpOnly, SameSite=Lax, 7 days absolute; sockets are
  closed on expiry, revoke, "This wasn't me" and deactivation; new token at login; raw Better Auth
  endpoints are not mounted.
- **OTP:** CSPRNG, hashed, 10 min TTL, 5 attempts consumed atomically, single use; domain rule exact
  and re-checked at verify and session creation; client IP cannot be spoofed behind the host Nginx.
- **CSRF / CORS:** origin check on every state-changing request; exact-match CORS; Socket.IO origin
  check.
- **Authorization:** every route behind `requireSession`/`requireAdmin`; no client-joinable chat
  rooms; membership re-checked at use time for messages, media, polls, calls, pins, stars, drafts,
  scheduled messages, folders, sessions, reports.
- **Input:** no `dangerouslySetInnerHTML`; links restricted to http(s)/mailto/tel; Zod on every
  route and event; escaped search regexes.
- **Link previews:** private/reserved IPv4/IPv6 blocked, DNS pinned, redirects re-checked (max 3),
  size and time caps, ports limited.
- **Media:** magic-byte allow-list; SVG/HTML only as attachments; sandbox CSP and `nosniff` on
  media; validated storage keys; signed links bound to id, purpose and expiry; view-once enforced on
  the server.
- **Infra (repo):** non-root images; only `127.0.0.1:7155/7156` published; Mongo and Redis
  internal; read-only root file systems, dropped capabilities; backups `umask 077`; startup env
  validation; test routes impossible in production; pino redaction of cookies, codes, tokens.
- **UAT:** no horizontal overflow at 360 px; no contrast violations in either theme; every Hindi key
  present; clear errors for wrong domain, invalid email and wrong code; offline banner, pending
  clock and resend on reconnect work; empty states present.
